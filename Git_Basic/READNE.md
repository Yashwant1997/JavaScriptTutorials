    - To create a git branch, use:                git branch <branch-name>
    - To create and switch to it immediately:     git checkout -b <branch-name>
    - To switch branches:                         git checkout <branch-name>
    - To commit and push code:                    git add .
                                                  git commit -m "your commit message"
    - To push code to a branch:                   git push origin <branch-name>
