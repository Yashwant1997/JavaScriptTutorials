# Javascript syntax : whitespace, statements, identifiers, comments, expressions, and keywords.
   - Whitespace : Carriage return, space, new line, tab + avaScript engine ignores whitespace. 
   - Statements : it is a piece of code that either declares a variable or instructs the JavaScript engine to perform a task.
                  ends with a semicolon but its optional
                  A block is a sequence of zero or more simple statements {} 

   - Identifiers : An identifier is a name you choose for variables, parameters, functions, classes, etc.
                   start with a-z/A-z/_/$ and followed by a-z/A-z/_/$
   - Comments : notes or hints in JavaScript code + JS engine ignores +// (single ilne) + /* */ (block comments)
   - Expression : piece of code that evaluates to a value
   - Keywords : Avoid using reserved keywords for identifiers.
